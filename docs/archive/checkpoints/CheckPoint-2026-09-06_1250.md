## Accomplishments

1. **v0.6.0** (commit `42b960a`): File > Exit menu item; two new optional
   fields (`Legal / Company Name`, `YACSS Listicle Display Title`, both
   default to `* Client Name` when blank) fixing a real gap found while
   reverse-engineering real client job JSON into this app's YAML format --
   a single "client name" field couldn't represent a client whose legal
   entity name differs from its brand name, or a listicle whose own
   display title is unrelated to the client's name; FAQ tab's Question/
   Answer columns now hold a stable 50/50 split; a real live bug fixed
   (`load_yaml` silently dropped digits from a phone number whose
   punctuation didn't match the `(000) 000-0000` input mask's literal
   positions -- found via a real client file, Royal Porta Johns); README.md
   (also the in-app Help -> How to Use text) rewritten as a current
   manual, documenting the Keyword Research tab, `YACSS Content Generation
   Mode`, and the required Diagram target-link-text fields (all previously
   shipped but undocumented).
2. **v0.7.0** (commits `ac0c87f`, `26c42ec`): new "Content Silo" tab -- a
   content pipeline for a client's OWN services/products silo (Category ->
   Service pages), independent of any YACSS job type. Two-pass DataForSEO
   clustering (categories, then services within each checked category, via
   the existing `keyword_research_api.fetch_clusters`) discovers the
   hierarchy; `silo_content_generator.py` (new module, mirrors
   `ai_content_generator.py`'s self-contained pattern) generates real
   landing-page-depth prose (title/meta description/intro/body/optional
   FAQs, plain prose, no spintax) per selected page, continuing past a
   single page's failure; Export Silo writes one Markdown file per
   successfully-generated page, reproducing the real category/service
   folder structure, plus an index. This tab's own state is deliberately
   excluded from `self.inputs`/`save_yaml`/`load_yaml` -- confirmed by its
   own test.
3. Full test suite: **163/163 passing** (was ~135 at session start; two
   new test files, `test_content_silo.py` and
   `test_silo_content_generator.py`, plus 2 new regression tests in
   `test_save_load_roundtrip.py` for the phone-mask fix).
