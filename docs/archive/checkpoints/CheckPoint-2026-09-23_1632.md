## Accomplishments

1. **v0.10.0 shipped** (`95c0fd6`, pushed to `origin/main`):
   - **"Content Image URLs (one per line)"** on the Content tab. Saved as a
     YAML list (added to `LIST_FIELDS`), exported as
     `CloudStackJob.content_image_urls` only when non-empty. Advisory
     warnings: filled in together with `Content Image URL` (rr_yacss_factory
     rejects the pairing), and more lines than the stack has pages.
   - **`Logo URL` now exports** to `logo_image_url` (Diagram only). It was
     collected but never read by any export. Behavior change: existing
     client files with a Logo URL start uploading it on the next factory
     run.
   - **Export-time image size check**: new `image_size_check.py`
     (`check_image_sizes`), called from `export_job_json` through
     `_image_size_warnings`. HEAD first, streamed GET fallback, 8 workers,
     5s timeout, descriptive User-Agent (Wikimedia 403s the default one).
     Checks hero, logo and each per-page image against 400,000 bytes.
     `Content Image URL` (single, direct URL, no cap) is skipped.
     `_build_cloud_stack_job` stays offline; only `export_job_json` hits the
     network.
2. **Live-checked** `image_size_check` against real URLs: a 537KB image was
   flagged, a small one was not, a 404 and an unresolvable host each produced
   the right warning.
3. Docs: README sections for the new field, Logo URL, and the size check
   (removed Logo URL from "Fields with no effect yet"); CHANGELOG v0.10.0.
   `__version__` 0.9.1 -> 0.10.0.

## Known issues

1. **Size check is advisory and network-dependent**: a host that blocks the
   check yields "could not be checked" or an HTTP 403/429 warning even if
   YACSS could fetch the image. Not verified: how large a real logo/hero the
   client files use.
2. The 400KB threshold is 400,000 bytes (stricter reading); the factory only
   knows the observed 413 on a 1320KB image.
3. The per-page images template quirk (first image also shown in a fixed
   second block) is documented in the factory README, not surfaced in this
   form beyond the README note.
4. Unchanged: Content Silo real-client validation still outstanding.
