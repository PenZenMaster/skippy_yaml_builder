## Accomplishments

1. **Venv consolidation** (commit `e401e49`): deleted the stale,
   undocumented `.venv/` (an older PyQt6 patch version that kept coming up
   when activating a venv by hand) so only the canonical `venv/` (matches
   README.md/`run.cmd`) remains at the repo root. Updated this project's
   own `CLAUDE.md` to drop the now-resolved two-venv caveat and updated
   `docs/projectStatus.md` so it doesn't resurface as an open item.
2. **v0.8.0** (commit `0cb399a`), two feature requests:
   - **"Generate FAQs from People Also Ask"** (FAQ tab): a new
     `keyword_research_api.fetch_people_also_ask` calls DataForSEO's
     Google SERP API (`serp/google/organic/live/advanced`) -- a genuinely
     different DataForSEO product from the Labs endpoints every other
     function in that module uses -- to pull up to 10 real Google PAA
     questions per click for the current seed keyword (same `YACSS Bucket
     Keyword`/`YACSS Topic Keyword` seed the Keyword Research tab already
     uses). A new `ai_content_generator.generate_faq_answers` then writes
     a real, business-specific answer for each question via the same
     OpenAI backend the Diagram/Content Silo AI features already use.
     Generated rows are appended to the FAQ table (never replace existing
     rows), and a question the model didn't answer is still added with a
     blank answer rather than silently dropped. Count is a 1-10 spinbox
     (default 5), enforcing the feature request's "maximum per cycle of
     10" both in the UI and as a hard clamp inside
     `fetch_people_also_ask` itself.
   - **Select All / Deselect All checkbox**: added above each of the
     three generated-results tables (Keyword Research's results table,
     both Content Silo tables) -- bulk-toggles every row's own "Use?"
     checkbox in one click. Each resets to unchecked automatically
     whenever its own table is freshly repopulated by a new research run,
     so a stale "checked" master checkbox never misrepresents a fresh set
     of unchecked rows. The two Content Silo checkboxes are independent
     of each other by design -- rebuilding the Services table resets only
     its own checkbox, never the Categories table's, since that table's
     checked rows are this run's own input.
3. Full test suite: **185/185 passing** (was 163 at session start; two new
   test files, `test_faq_paa_generation.py` and
   `test_select_all_checkboxes.py`, plus new cases added to
   `test_keyword_research.py` and `test_ai_content_generator.py`).
