  job: stops on warnings, checks the pinned bucket exists on every tier

- **Per-stack landing pages and claim-free titles** (`9e93974`,
  2026-11-06). `--landing-url` points a stack's backlink at the client's
  page for that service; `--link-topic` overrides the topic in the link
  sentence. The profile's link sentence now ends "to learn more about
  `{service}`.", with `{service}` read from the landing page's address.
  Research titles about cost, price, "how much" and "near me" are skipped;
  the AI title prompt forbids claims ("leading", "trusted", "best",
  "affordable"...), and AI titles that still make claims are dropped.
  Titles step factored into `make_titles()`. Used for seven USS stacks
  (builds 133409-133415, 91 pages live, each tier 1 page linking to its
  own service page).

  Overhead Door Joliet batch (24 stacks x 74 images + hero + logo) hit
  YACSS's limit of 300 image uploads per 24 hours before any stack was
  drafted. Cloud Stack jobs now get exactly one image per page
  (`job_export.select_content_images`); a 14-page stack needs 16 uploads.
  autobuild's new `--batch-position N` starts stack N at image
  N x pages + 1, wrapping round, so a batch's stacks use different images.
  The "extra images will never be used" warning is removed. The saved
  client YAML keeps the full list. The app's Export Job JSON always uses
  position 0.
